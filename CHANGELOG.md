# Changelog

## Unreleased

### Added

- Lista de entregas con curso, vencimiento y acciones para completar localmente
  o abrir la tarea en el navegador.
- Lista de avisos pendientes que permite descartarlos sin perder otros eventos.

### Changed

- Concentrarme inicia el Pomodoro; las animaciones de prueba quedan en el
  apartado avanzado.
- Controles más grandes, textos con mayor contraste y navegación de teclado
  visible en el panel, con adaptación a ventanas estrechas.

### Fixed

- Las alertas académicas urgentes conservan prioridad frente a celebraciones
  de GitHub y avisos de fin de sesión.
- El personaje utiliza datos reales de la entrega y recupera la concentración
  después de un aviso temporal.
- La validación de calendario permanece visible entre actualizaciones y los
  fallos al cargar un personaje conservan la selección anterior.
